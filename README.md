## 🚀 Deployment (Vercel)

This repository is optimized for instant deployment with **Vercel**:
- `vercel.json` provides clean URLs and global edge caching for `/assets/*`.
- Standalone zero-dependency architecture (pure HTML5, CSS3, Vanilla JS).

### Local Preview
```bash
python3 -m http.server 8000
# or
npx serve .
```
Visit `http://localhost:8000` in your browser.
